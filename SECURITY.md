# Security

If you find a security problem in proDOCKtivity, please email [prodocktivity@bennet-gibony.com](mailto:prodocktivity@bennet-gibony.com) instead of opening a public issue. Include what you found and how to reproduce it. I'll reply as soon as I can.

The app runs locally, has no account system and sends no telemetry. The few network connections it makes are listed in the README under "Privacy".
